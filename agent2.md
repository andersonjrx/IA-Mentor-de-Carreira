## 🚀 Projeto de Portfólio
**Projeto:** *Mini Rede Social*  

### O que fazer
Criar uma aplicação web onde usuários podem se cadastrar, postar mensagens e interagir.  

### Entregáveis
- Front-end responsivo (HTML, CSS, JS/React)  
- Back-end com API REST (Node.js + Express)  
- Banco de dados para armazenar usuários e posts  

### Critérios de Aceitação
- Cadastro/login funcionando  
- CRUD de posts  
- Deploy online acessível  

**Dica:** Comece simples e vá adicionando funcionalidades extras (curtidas, comentários) conforme evoluir.

➡️ Var é antigo, let tem escopo de bloco, const é imutável.  

**Pergunta 3:** "O que é uma API REST?"  
➡️ Padrão de comunicação entre sistemas usando HTTP e recursos.  

**Pergunta 4:** "Como você organiza seu código em projetos?"  
➡️ Cite boas práticas: modularização, uso de Git, separação front/back.  

**Pergunta 5:** "Por que você escolheu trabalhar com JavaScript?"  
➡️ Mostre entusiasmo: linguagem versátil, usada tanto no front quanto no back.
